# دستیار خطرات محیط کار — پروژه Capacitor

این پوشه یک پروژه کامل Capacitor است که اپ HTML (در `www/index.html`) را به یک اپ اندروید نیتیو تبدیل می‌کند. همه‌چیز آماده است؛ فقط کامپایل نهایی باقی مانده که نیاز به Android SDK و اینترنت آزاد دارد (چیزی که در محیط من در دسترس نبود).

## چه کاری از قبل انجام شده

- پروژه Capacitor ساخته و پیکربندی شده (`capacitor.config.ts`)
- پلتفرم اندروید اضافه شده (`android/`)
- دسترسی میکروفون سیم‌کشی شده: مجوز `RECORD_AUDIO` در Manifest اضافه شده و `MainActivity.java` طوری تنظیم شده که درخواست میکروفون از سمت صفحهٔ وب (ماژول صدا) را خودکار تأیید کند
- رنگ‌بندی برنامه (پس‌زمینه تیره و کهربایی) با تم اصلی اپ هماهنگ شده
- نام اپ به فارسی تنظیم شده: «دستیار خطرات محیط کار»
- یک فایل GitHub Actions (`.github/workflows/build-apk.yml`) اضافه شده تا در صورت تمایل، بدون نصب هیچ نرم‌افزاری، APK به‌صورت خودکار در فضای ابری ساخته شود

## گزینهٔ ۱ — ساخت با Android Studio (پیشنهادی، سریع‌ترین راه)

1. [Android Studio](https://developer.android.com/studio) را نصب کن (خودش SDK لازم را دانلود می‌کند)
2. این پوشه (`hse-toolkit`) را باز کن: File → Open → پوشهٔ `hse-toolkit/android` را انتخاب کن
3. صبر کن تا Gradle Sync تمام شود (بار اول چند دقیقه طول می‌کشد، چون Android Studio باید Gradle و SDK را دانلود کند)
4. از منو: Build → Build Bundle(s) / APK(s) → Build APK(s)
5. فایل APK در مسیر `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود
6. این فایل را روی گوشی کپی کن و نصب کن (باید «نصب از منابع ناشناس» را در گوشی فعال کنی)

برای اجرای مستقیم روی گوشی متصل با کابل: در Android Studio دکمهٔ ▶ Run را بزن.

## گزینهٔ ۲ — ساخت خودکار در فضای ابری (بدون نصب هیچ‌چیز)

اگر این پوشه را در یک ریپازیتوری GitHub قرار بدی:

1. یک ریپازیتوری جدید در GitHub بساز و این پوشه را push کن
2. به تب Actions در ریپازیتوری برو
3. workflow با نام «Build APK» را پیدا کن و «Run workflow» را بزن
4. بعد از چند دقیقه، فایل APK ساخته‌شده به‌عنوان یک Artifact قابل دانلود در همان صفحه ظاهر می‌شود

این روش از سرورهای گیت‌هاب استفاده می‌کند که دسترسی کامل به اینترنت و Android SDK دارند، پس محدودیتی که من داشتم را ندارد.

## نکات مهم قبل از انتشار واقعی

- این APK فعلی **امضای دیباگ (debug signing)** دارد، یعنی فقط برای تست روی گوشی خودت مناسب است، نه انتشار در Google Play. برای انتشار رسمی باید یک کلید امضای release بسازی (`keytool` یا از داخل Android Studio: Build → Generate Signed Bundle / APK).
- شناسهٔ اپ فعلاً `com.apollo.hsetoolkit` است؛ اگر بخوای می‌تونیم عوضش کنیم.
- آیکون اپ فعلاً همون آیکون پیش‌فرض Capacitor است؛ اگر لوگو داری بفرست تا جایگزینش کنم.
